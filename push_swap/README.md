# Push_swap

## Description
**push_swap** is an individual algorithmic project at 42 that challenges us to sort a stack of integers using a limited set of operations and the minimum possible number of moves. 

The main goal of the project is to write a C program named `push_swap` that takes a list of integers as arguments, calculates the most efficient sequence of sorting instructions, and prints them to the standard output. 

To succeed, the project requires a deep understanding of data structures (specifically stacks implemented using linked lists or arrays), complexity management, and optimization strategies for both small sets (3 to 5 numbers) and large sets (100 to 500 numbers).

The project includes a `Makefile` that compiles the source files using `gcc` with the mandatory flags (`-Wall -Wextra -Werror`).

- `make fclean` — removes object files and the `push_swap` binary.

## Algorithm Choice and Justification

For this project, we implemented a hybrid sorting strategy customized for different input sizes to ensure both speed and compliance with 42 grading thresholds (< 700 instructions for 100 numbers and < 5500 for 500 numbers):

1. **Small Sets (3 to 5 elements):**
   - **Hardcoded Logic / Permutations:** For 3 elements, all possible permutations can be sorted in a maximum of 2 actions using simple conditional checks. For 5 elements, we push the two smallest numbers to stack B, sort the remaining 3 in stack A, and push them back, ensuring optimal performance.

2. **Large Sets (100 to 500 elements):**
   - **Cost-Analysis / Turk Algorithm:** We selected a cost-evaluation algorithm. Instead of sorting blindly, every element in stack B is evaluated to find the cheapest move to stack A based on the total number of combined rotations (`ra`, `rb`, `rra`, `rrb`, `rr`, `rrr`) required for both stacks. This drastically reduces overall operations and maintains high efficiency.
