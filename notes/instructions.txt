STEP 1c - RANKS (new file src/stack/ranks.c) - uses OUR insertion_sort!
 [ ] Copy all stack values into an int array.
 [ ] Sort the copy with practice/insertion_sort.c (move it into src).
 [ ] If two neighbours in the sorted copy are equal -> duplicate -> Error.
 [ ] Give every node a rank: its position in the sorted copy (0..n-1).
     Add "int rank;" to t_node.
     Why: 5 -300 42 becomes 1 0 2. Chunks and radix work on ranks,
     so negative and huge numbers stop being a problem.

--------------------------------------------------------------------
STEP 4 - SIMPLE STRATEGY  O(n^2)  (src/strats/simple_strat.c)
--------------------------------------------------------------------
Uses OUR selection_sort idea:
  repeat: find the min in A -> ra or rra (whichever is shorter) until
          min is on top -> pb.   When A is empty -> pa everything back.
 [ ] helper: position of the min node
 [ ] special case: 2 and 3 numbers (3 numbers needs max 2 ops)
 [ ] special case: 5 numbers (push 2 smallest, sort 3, pa pa)
Test: count ops with  ./push_swap ... | wc -l


--------------------------------------------------------------------
STEP 5 - MEDIUM STRATEGY  O(n*sqrt(n))  (src/strats/medium_strat.c)
--------------------------------------------------------------------
Uses OUR chunk_sort idea, but on RANKS (step 1c) instead of values:
  chunk size ~ sqrt(n). For each chunk: pb every node whose rank is in
  the chunk (ra past the others). Then bring them back: find the max in
  B, rb/rrb to top, pa. Repeat.
 [ ] 100 numbers must be < 2000 ops (aim for < 1500)


--------------------------------------------------------------------
STEP 6 - COMPLEX STRATEGY  O(n log n)  (src/strats/complex_strat.c)
--------------------------------------------------------------------
Radix on the BITS of ranks (write it ourselves, not the geeksforgeeks one):
  for each bit (0, 1, 2 ...): go through A once:
      bit is 0 -> pb,  bit is 1 -> ra.   then pa everything back.
 [ ] 500 numbers must be < 12000 ops
 Later, if we want "excellent" (< 5500 for 500), we can improve this.


--------------------------------------------------------------------
STEP 7 - ADAPTIVE + FLAGS  (src/strats/adaptive_strat.c)
--------------------------------------------------------------------
 [ ] disorder < 0.2        -> O(n) method (stack is almost sorted:
                              few swaps / rotations to fix it)
 [ ] 0.2 <= disorder < 0.5 -> medium strategy
 [ ] disorder >= 0.5       -> complex strategy
 [ ] main picks strategy from the flag, default = adaptive
